Study groups often revolve around whoever has the best notes, the clearest summary, or the practice problem set everyone actually needs. Getting everyone looking at the same material at the same time is half the battle — especially when the group isn't all in the same room, or is scattered between a dorm, a library, and someone's kitchen table the night before an exam.

## Group chats aren't built for "watch this with me"

Sending a photo of notes or a link to a shared doc works, but it's static — someone has to describe what they're pointing at, and it's easy for the group to end up looking at slightly different things (an outdated version of the doc, a photo that's slightly blurry, a screenshot that's already stale). What actually helps is everyone seeing the same screen, live, while whoever's presenting talks through it and scrolls at a pace the group can follow.

## Setting up a session in under a minute

1. Whoever has the material opens [quiicast.com/caster](/caster) and clicks **Start sharing my screen**.
2. They pick the window or tab with the notes, slides, or problem set, and get a 4-digit code.
3. That code gets dropped in the group chat — no explanation needed beyond "join with this code."
4. Everyone else opens [quiicast.com/receiver](/receiver) on their own laptop or phone, types the code, and is watching within seconds.

Up to 5 people can join a single code, which covers most study groups without anyone needing to sign up for anything. Because there's no account needed on either side, it's genuinely as fast as sending a message and having everyone join within a minute.

## Good ways to use it

- One person walks through practice problems while everyone follows along and asks questions
- Reviewing shared class notes together instead of everyone squinting at a photo
- Going through a professor's slides section by section as a group
- A quick last-minute review session that doesn't need to be scheduled in advance
- Watching a recorded lecture together and pausing to discuss confusing parts, without everyone needing the same streaming login

## Tips for a smoother session

- If most of the group is on phones, tell the presenter to zoom in on text before sharing rather than relying on everyone pinch-zooming their own tiny video feed.
- On a shared school or library WiFi network, sessions still work over the open internet by default — "Prefer local WiFi" is only worth turning on if everyone in the group is physically on the same network.
- Since the code is a fresh one each time you start a session, there's nothing left over to worry about once everyone's done and closes the tab.

## FAQ

**Does everyone need to create an account?**
No — neither sharing your screen nor watching one requires signing up. Anyone with the 4-digit code and a browser can join.

**What if someone's on a school Chromebook with restricted extensions?**
QuiiCast doesn't need any browser extension — it runs entirely in a standard tab, so managed/restricted school devices generally work fine as long as the browser itself isn't blocked from the site.

**How long does the code last?**
Codes expire after a few minutes of not being used and automatically refresh while the caster keeps sharing, so a study session that runs long doesn't get interrupted — latecomers just need the newest code if the original one already timed out.

It's casual by design — there's no recording, no persistent classroom, nothing to set up beforehand. Just a code, and everyone looking at the same screen.
